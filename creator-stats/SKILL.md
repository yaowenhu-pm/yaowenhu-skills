# Creator Stats — 抖音/小红书创作者大盘数据批量录入

## 原理（为什么这么做）

粉丝数、获赞数是公开数据，就渲染在主页上；唯一障碍是反爬。而反爬对抗的是
**机器指纹**（签名参数、无头浏览器特征），不是**浏览行为**。所以不写爬虫、
不碰 X-Bogus/x-s 签名，直接驱动用户本人登录态的真实 Chrome 逐页打开主页，
在平台眼里就是正常浏览。抓取用 `get_page_text` 纯文本解析，连 JS 注入都不需要。

规模预期：几百个账号 × 每页 3~6 秒节流 ≈ 0.5~1.5 小时。

## 前置检查（缺一不可，先确认再开跑）

1. **Claude in Chrome 扩展已连接**：`tabs_context_mcp{createIfEmpty:true}` 能返回 tab。
2. **抖音、小红书都已登录**：各开一个主页确认能看到粉丝数。抖音未登录几秒后
   弹扫码登录墙（数字为空），小红书未登录直接跳登录页——两个都必须让用户扫码。
3. **让用户暂停 Workona 等标签管理器**：它们会回收自动化标签组，导致大量重试。

## Step 1 — 链接归一化

用户把链接清单存成文本（格式随意，短链长链混着无所谓）：

```bash
python3 scripts/normalize.py input_links.txt   # 产出 normalized.csv
```

短链 302 解析不需要任何签名；小红书链接里的 `xsec_token` 会保留（无 token
直访更容易被风控弹登录）。

## Step 2 — 浏览器批量采集

对 `normalized.csv` 每行执行固定配方：

1. `tabs_context_mcp{createIfEmpty:true}` 拿到 tabId
2. `browser_batch`: `[navigate 主页URL, computer:wait 4秒, get_page_text]`
3. 把 get_page_text 输出喂给解析脚本（stdin），立即落盘：

```bash
python3 scripts/parse_stats.py --url <主页URL> --raw <原始链接> --seq <序号> \
    --out results.csv < pagetext.txt
```

4. 节流：每页再等 2~4 秒；每 30~50 个歇 1~2 分钟。

### 实战坑速查表（每一条都是真实踩过的）

| 现象 | 真相 | 处置 |
|------|------|------|
| `browser_batch` 报"did not respond in time" | **动作多半已执行完** | 别重发 batch，直接补一次 `get_page_text`，通常能拿到数据 |
| "Tab no longer exists" | **常是假错**，标签页还活着 | 重新 `tabs_context_mcp` 确认后立即重试；组真没了就 createIfEmpty 重建接着跑 |
| 小红书跳转到 `/login?redirectPath=...` | 偶发风控误伤（登录态正常） | 同链接重试 1~2 次即恢复；解析脚本会记"需登录/被风控跳转"状态，收尾统一重跑 |
| 抖音数字为空但昵称有 | 页面没渲染完或未登录 | wait 加到 5~6 秒重试；仍空则检查登录态 |
| 弹滑块验证码 | 频率触顶 | 暂停，叫用户手动滑一下，加大间隔继续 |

### 解析规则（parse_stats.py 已固化，无需肉眼）

- **抖音**是"标签→数字"：`关注\n50\n粉丝\n8.3万\n获赞\n33.3万`，另有
  `抖音号：X`、`IP属地：Y`（或"浙江·杭州"式地区行）、作品数在`作品\nN`。
  注意导航栏也有"关注"两字，必须认"下一行是数字"的那个。
- **小红书**是"数字→标签"：`46\n关注\n207\n粉丝\n4303\n获赞与收藏`，另有
  `小红书号：X`、`IP属地：Y`，昵称在"小红书号"上一行。
- 数字归一化 `8.3万→83000`、`3亿→300000000`，同时保留原文列防回溯。
- **已知局限**：小红书网页版主页不显示笔记总数，"作品/笔记数"列小红书留空。

## Step 3 — 产出与校验

- `results.csv` 表头：序号,平台,昵称,账号ID,粉丝数,获赞数,关注数,作品/笔记数,
  IP属地,简介,粉丝数原文,获赞数原文,主页URL,原始链接,采集时间,状态
- 每抓一条立即 append（断点续跑：按序号跳过已有行）
- 收尾三件事：① 状态≠ok 的行集中重跑一遍；② 随机抽 10 行开页面人工比对；
  ③ 行数应等于去重后链接数。

## 红线

- 只读公开主页大盘数据，不采集内容/评论，不绕验证码（验证码永远交给用户手动）。
- 节流下限 3 秒/页不许压缩——快 10 分钟不值得账号被风控。
