# hr-autopilot 使用说明：请假审批到考勤全自动

员工在飞书请假 → 审批通过后自动写入考勤表 + 请假记录留痕 → 双向通知。

> ⚠️ 薪资模块已于 2026-07-06 按数据安全要求下线：小潜 App 凭证全公司共享，App 可读的表格不得存放真实薪资。薪资管理表及员工表薪资列已移除，绝不在本表格任何字段填真实薪资。考勤数据可导出供 HR 在小潜无权限的私有表格中另行算薪。

## 员工怎么请假

- **私聊小潜一句话**（推荐）："我明天请一天事假"——审批卡片秒级发给毅哥，结果自动通知你
- 或照常走**审批中心**提请假（每小时自动同步）

## 前置条件

- 一台常开的 Mac / Linux 电脑（脚本靠系统定时任务运行）
- 多维表格需包含：员工管理、考勤管理、加班管理（请假记录表自动创建）
- 表格右上角 `···` → 更多 → 添加文档应用 → 搜「小潜」→ 给**可编辑**权限

## 安装（3 分钟）

```
git clone https://github.com/infidive-ai/skills.git ~/infiDive-skills   # 已有则 git pull
cd ~/infiDive-skills/hr-autopilot && ./install.sh
```

装完后只做一件事：**员工管理表**给每个员工绑定「飞书账号」列（@到本人，这是请假审批关联到员工的唯一依据）。

## 考勤规则（config.json 可改，改完即生效）

| 规则 | 默认值 |
| --- | --- |
| 大小周 | 已启用：7-11 为班六，两周一循环；班六算工作日（请假要计天） |
| 年假额度 | 5 天/年，使用自动累计，年假剩余表内公式实时算 |
| 请假跨月 | 全部天数计入开始日期所在月 |

## 常见问题

- **请假没同步**：查该员工「飞书账号」列是否绑定；审批名称需含"请假/休假"；日志在 `logs/sync.log`。
- **私聊小潜请假没回"已提交"**：常驻服务离线（宿主机睡眠等），稍后重发一句，或走审批中心。
- **手动改了表格**：即刻被感知，脚本每次运行实时读表。
- **电脑关机了**：开机后下个整点自动补同步，审批回看 92 天，不漏单。
- **卸载**：`crontab -l | grep -v hr-autopilot | crontab -`
